Алгоритъм на контролната цифра / Checksum algorithm

Тежести на първите 9 цифри: 2, 4, 8, 5, 10, 9, 7, 3, 6. Контролната е (сума mod 11) mod 10. 

// JavaScript / JS
const w = [2,4,8,5,10,9,7,3,6];
const sum = w.reduce((s, wi, i) => s + wi * +egn[i], 0);
const check = sum % 11 % 10;
return check === +egn[9];
1–13 април 1916 не съществуват — България преминава от Юлиански към Григориански календар, пропускайки 13 дни.
1–13 April 1916 don't exist — Bulgaria adopted the Gregorian calendar by skipping those 13 days. EGNs carrying such dates are invalid.
